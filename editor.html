Paste the plain text of a TripIt-style itinerary (print view / forwarded confirmations). Flights and check-in/out lines are extracted best-effort; the draft lands in the Config tab for you to finish.

What a trip config looks like

One JSON object with title, places, legs, and optionally stays, events, focus and calendarOffset. Load the demo from the toolbar to see a complete working example.

places — object keyed by a short id you invent (e.g. "par")

fieldmeaning
ndisplay name, e.g. "Paris"
rregion line shown in tooltips, e.g. "Île-de-France, France"
cccountry — used for the country count and the default Focus region
lat, loncoordinates in decimal degrees
offUTC offset in minutes during your visit (Paris in summer = 120, Phoenix = -420)
coptional hex colour; auto-assigned when omitted
lbloptional map-label placement [dx, dy, anchor, tier]: pixel nudge, "start"|"middle"|"end", and the zoom tier (1 = always visible … 4 = only when zoomed right in). Auto when omitted.

legs — array; each leg should start where the previous one ended

fieldmeaning
modeflight · bus · car · train · ferry · gap (use gap for unbooked stretches — they render dashed and count as open days)
from, toplace keys
dep, arrISO 8601 with UTC offset, e.g. "2026-07-29T11:30:00-07:00"
title, opoptional headline and operator/detail line
warn, detoptional watch-out text and long details (shown when a card is expanded)

stays — array of lodging bookings

fieldmeaning
placeplace key
name, addrlodging name and address line
in, outcheck-in / check-out, ISO 8601 with offset
lat, lonoptional exact pin (defaults to the place); shows when zoomed to street level
detoptional details — door codes, confirmation numbers, and so on. Stored only in your browser, but remember anything you publish is visible to whoever can open the page.

events — array of everything else

fieldmeaning
kindactivity (tours, meetups), note (reminders, deadlines), gapnote (annotates an open stretch)
placeplace key
start, endISO 8601 with offset; end optional
lat, lon, addroptional meeting point, pinned on the zoomed-in map
warn, det, offoptional; off overrides the display timezone for this one item

top-level extras

  • focus: array of place keys the map's Focus button fits. Default: every place outside the origin's country.
  • calendarOffset: UTC offset in minutes that defines where a "day" starts/ends in the calendar and scrubber ticks. Default: the offset where you spend the most time.

Minimal example

{
  "title": "A weekend away",
  "places": {
    "hom": {"n":"Home City","r":"","cc":"USA","lat":40.7,"lon":-74.0,"off":-240},
    "chi": {"n":"Chicago","r":"Illinois","cc":"USA","lat":41.88,"lon":-87.63,"off":-300}
  },
  "legs": [
    {"mode":"flight","from":"hom","to":"chi",
     "dep":"2026-10-02T08:00:00-04:00","arr":"2026-10-02T09:30:00-05:00","op":"XX 123"},
    {"mode":"flight","from":"chi","to":"hom",
     "dep":"2026-10-04T18:00:00-05:00","arr":"2026-10-04T21:10:00-04:00","op":"XX 124"}
  ],
  "stays": [
    {"place":"chi","name":"Loop Hotel","in":"2026-10-02T15:00:00-05:00","out":"2026-10-04T11:00:00-05:00"}
  ],
  "events": [
    {"kind":"activity","place":"chi","title":"Architecture boat tour",
     "start":"2026-10-03T10:00:00-05:00","end":"2026-10-03T11:30:00-05:00"}
  ]
}

Tips

  • All times need an explicit UTC offset — that is what makes the timezone math work without a timezone database.
  • Model an unbooked stretch as a leg with "mode":"gap" spanning the whole hole; it shows dashed on the map and feeds the "gaps" stat.
  • Trips are saved in this browser's localStorage. Use Export file for backups or to move a trip between devices.
